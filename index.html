What is Smart Notes?

Smart Notes is a modern web-based note-taking application designed to help you organize, search, and manage your notes efficiently. Built with pure HTML, CSS, and JavaScript, it works completely offline with no server required.

Key Features

  • Create and edit notes
  • 5 beautiful color options
  • Smart search functionality
  • Pin important notes
  • Dark mode support
  • Fully responsive design

Technology Stack

Frontend: HTML5, CSS3, JavaScript ES6+

Storage: Browser Local Storage (10 MB capacity)

Icons: Font Awesome 6.4

Fonts: Google Fonts (Poppins)

Version & Info

Version: 1.0.0

Type: Web Application

Availability: Offline / No server required

Browser Support: All modern browsers
